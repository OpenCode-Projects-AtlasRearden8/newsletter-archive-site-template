# AI Coding Tools You Can Use Free Right Now

You do not need a paid plan to let AI help you write your first programs.
Here is an honest tour of the free options, and what each one is actually
good at.

## Tier one: free browser assistants

- **Web chat assistants** like ChatGPT, Claude, and Gemini all have free
  tiers. Great for asking "why does my code crash?" with the error pasted
  in.
- **Honest limits**: free tiers may throttle you at busy times and often
  use smaller models. Fine for learning.

## Tier two: free coding help inside your editor

1. Install VS Code (free)
2. Add an AI assistant extension with a free tier
3. Ask it to explain a file before you change anything

> Rule of thumb: let the AI *explain first*, *edit second*, and *never*
> paste in passwords, keys, or personal data.

## A tiny first task

```python
# Ask the assistant: "add a docstring and type hints here"
def add(a, b):
    return a + b

print(add(2, 3))  # should print 5
```

## What to try this weekend

1. Ask an assistant to explain a short script you found online
2. Change one thing, run it, see what breaks
3. Fix it with a second question

That loop — explain, tweak, fix — is 80% of AI-assisted coding.
